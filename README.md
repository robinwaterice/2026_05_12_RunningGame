# Pixel Chameleon (像素變色龍跑酷)

這是一款使用 React, TypeScript, 以及 HTML5 Canvas 製作的無盡跑酷遊戲 (Endless Runner Game)。
玩家需要點擊畫面或按下空白鍵來操作角色跳躍，躲避仙人掌障礙物，同時收集金幣與變身道具來獲得高分！

## 遊戲特色 / Features

- 🏃‍♂️ **無盡跑酷**：遊戲節奏會隨著分數提升而加快。
- 🪙 **金幣收集**：跳躍並收集金幣來獲得額外加分。
- 📦 **變身系統**：吃到隨機出現的神奇箱子，角色會隨機變身成機器人、狗狗或 UFO 等不同外觀！
- 🏆 **最高分紀錄**：會將你的最高分數記錄在瀏覽器的 Local Storage 中。
- 🎨 **像素風格**：使用 Canvas 繪製可愛的像素美術風格 (Pixel Art) 與粒子特效。

## 如何在本地端執行 / Run Locally

**環境要求 (Prerequisites):** Node.js

1. 安裝依賴套件 (Install dependencies):
   ```bash
   npm install
   ```
2. 啟動開發伺服器 (Run the app):
   ```bash
   npm run dev
   ```
3. 打開瀏覽器並前往終端機顯示的本地網址 (例如: `http://localhost:3000`) 即可開始遊玩！
